**FULFSE STORAGE** (*Fluxo Unificado de Limiar Fractal em Superfície Estendida — Sistema Termodinâmico de Armazenamento e Retificação de Gradiente Entrópico*) é um dispositivo teórico de propulsão quântica desenvolvido para aplicações em veículos aéreos não tripulados de longa duração.

Este repositório contém um site interativo de uma única página que demonstra o funcionamento do motor através de uma visualização 3D em tempo real, permitindo explorar cada uma das 7 camadas concêntricas do sistema.

---

## Aviso Importante

> **Este é um projeto de worldbuilding e ficção científica especulativa (Hard Sci-Fi).**
>
> O motor FULFSE STORAGE **não é fisicamente realizável** com a tecnologia e as leis da física atuais. Ele viola princípios fundamentais como a 2ª Lei da Termodinâmica e esbarra no problema da decoerência quântica em escala macroscópica.
>
> O projeto foi concebido como **experimento mental** e peça de narrativa, utilizando conceitos reais de física de fronteira (cristais de tempo, isolantes topológicos, efeito Zeno quântico, limite de Bekenstein) extrapolados de forma criativa.
>
> **Aplicações recomendadas:** livros, roteiros, jogos, RPGs, arte conceitual, design especulativo.
> **Não recomendado para:** trabalhos acadêmicos reais, pitches de engenharia ou alegações de invenção funcional.

## Funcionamento do Motor

### Arquitetura em Camadas

O motor é construído como uma "cebola termodinâmica" com 7 camadas concêntricas, cada uma com funções específicas no gerenciamento do gap quântico-termodinâmico:

| Camada | Nome | Material Principal | Função Sistêmica |
|:---:|---|---|---|
| **00** | Núcleo de Cristal de Tempo | 1T-TaS₂ + Férmions de Majorana | Fonte de oscilação atômica perpétua (0,003 K) |
| **01** | Matriz de Retificação | Grafeno bicamada torcido (1,1°) + GaAs | Retifica flutuações do vácuo em 48V DC |
| **02** | Processador Zeno | Nióbio supercondutor (2.048 qubits) | Medição fraca contínua · Efeito Zeno |
| **03** | Isolante Topológico 3D | Bi₂Se₃ nanostruturado + Sb | Barreira unidirecional de entropia |
| **04** | Casca Holográfica (STORAGE) | Nanotubos de carbono + Grafeno | Armazena entropia · Limite de Bekenstein |
| **05** | Atuadores Piezoelétricos | PZT nanoescala (6 anéis) | Propulsão por ondas acústicas (80 kHz) |
| **06** | Interface Ambiental | Aerogel de sílica + Au | Dissipação final · Halo Entrópico |

### Ciclo Operacional

O motor opera em 5 fases principais:

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  FASE 1     │───▶│  FASE 2     │───▶│  FASE 3     │
│  IGNIÇÃO    │    │  BLOQUEIO   │    │  AUTO-      │
│  0s → 3s    │    │  ZENO       │    │  SUSTENTAÇÃO│
│             │    │  3s → 5s    │    │  5s → 8s    │
└─────────────┘    └─────────────┘    └─────────────┘
                                              │
                                              ▼
┌─────────────┐                    ┌─────────────┐
│  FASE 5     │◀───────────────────│  FASE 4     │
│  DESLIGA-   │                    │  CRUZEIRO   │
│  MENTO      │                    │  ∞          │
│  3s         │                    │             │
└─────────────┘                    └─────────────┘
```

| Fase | Duração | Evento Crítico |
|---|---|---|
| **1 · Ignição** | 0 → 3s | Resfriamento por diluição · Núcleo a 0,003 K |
| **2 · Bloqueio Zeno** | 3 → 5s | Estabilização quântica · Pulso EM 2,4 GHz |
| **3 · Auto-Sustentação** | 5 → 8s | Retificação do vácuo · Desconexão da bateria |
| **4 · Cruzeiro** | Indefinido | Equilíbrio termodinâmico aberto |
| **5 · Desligamento** | 3s | Retorno ao estado fundamental · Flash IR |

## Modos de Falha

### Falha Alpha — Latência Zeno
- **Causa:** Decoerência de qubits no Processador Zeno
- **Sintoma:** Oscilação entre potência total e zero em ciclos de 200 ms
- **Consequência:** Pousos forçados a cada 40 segundos
- **Recuperação:** Recalibração criogênica (30 min)

### Falha Beta — Saturação do STORAGE
- **Causa:** Operação > 72h em carga máxima sem descarga
- **Sintoma:** Emissão azul-violeta visível · Núcleo aquece 0,1 K/h
- **Consequência:** Implosão termodinâmica em 3 ms · Onda de choque a -40°C
- **Recuperação:** Nenhuma · Motor irrecuperável

### Falha Gamma — Fadiga Topológica
- **Causa:** Microfraturas no Isolante Topológico após ~18.000 h
- **Sintoma:** Vazamento de entropia de volta ao núcleo
- **Consequência:** Perda de 2% de potência/mês
- **Recuperação:** Substituição preventiva da Camada 3 a cada 16.000 h
